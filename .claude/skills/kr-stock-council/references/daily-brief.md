# 아침 브리핑 — 매일 05:30

전체 협의체(4라운드)를 매일 돌리지 않는다. **주간 정밀 점검과는 다른 모드**다.

## 하루의 흐름 — 두 번에 나눠서 받는다

| 시각 | 누가 | 무엇을 |
|---|---|---|
| **전날 저녁** | 사용자 | 그날 종가 캡처를 보낸다 |
| 전날 저녁 | 나 | 받는 즉시 `data/prices-YYYYMMDD.json`에 저장하고 **커밋한다**. 이때 브리핑은 내지 않는다 |
| 22:30~05:00 | 미국장 | (서머타임 기준) |
| **05:30** | 사용자 | **"브리핑"** 이라고 친다 ← 이게 신호다 |
| 05:30 | 나 | 밤사이 미국장·지정학을 확인하고 **HTML 아티팩트**로 낸다 |

종가를 전날 저녁에 미리 받아두는 게 핵심이다. 그래야 아침 5시 반에
사용자를 기다리게 하지 않고 바로 결론부터 낼 수 있다.

**저녁에 캡처를 받으면 저장만 하고 분석을 시작하지 않는다.**
미국장이 아직 안 끝났으므로 그때 낸 판단은 몇 시간 뒤 무효가 된다.
"저장했습니다, 내일 05:30에 브리핑하겠습니다" 한 줄이면 된다.

## 종가는 반드시 본장(정규장) 기준

증권사 앱 시세 화면은 **넥스트장(NXT)까지 포함한 값**을 보여줄 수 있다.
8/14 현대차가 본장 453,000인데 앱에는 459,500으로 떴다. 이걸 모르고
"지금 가격에 매도" 주문을 459,000에 걸면 **이미 현재가보다 위**라서 체결되지 않는다.

시계열도 본장으로만 쌓는다. 넥스트장은 유동성이 얕아 변동성이 왜곡된다.
**네이버 금융 일별 탭이 본장 종가**이므로 그쪽을 기준으로 삼고,
증권사 앱 값과 다르면 네이버 쪽을 쓴다.

## 신호어 — "브리핑"

사용자가 **"브리핑"** 한 단어만 쳐도 이 모드다. 자동 실행은 걸려 있지 않으므로
그 말이 오기 전에는 아무것도 하지 않는다. 되물어보지 말고 바로 낸다 —
필요한 건 전날 저녁에 이미 다 받아뒀다.

## 이 모드의 첫 번째 규칙

**대부분의 날은 "오늘은 아무것도 안 함"이 정답이다.**

매일 브리핑을 내다 보면 매일 뭔가 할 일을 만들어내게 된다. 그건 분석이 아니라
매매 유도다. 이미 걸어둔 예약주문이 그대로 유효하면 **"변경 없음"이라고 쓰고 끝낸다.**
없는 액션을 지어내지 않는다.

액션이 나오는 건 이 셋 중 하나일 때만이다:

1. **걸어둔 트리거 가격이 닿았다** (매도 구간 도달, 손절선 이탈, 추매 구간 진입)
2. **보유 종목에 직접 영향을 주는 사건이 밤사이 있었다** (실적, 관세, 리콜, 규제, 지정학)
3. **이평선 배열이 바뀌었다** (정배열↔역배열 전환, 60일선 돌파·이탈)

## 두 번째 규칙 — 장중에는 아무것도 못 한다

사용자는 09:00~15:30에 회사에 있다. **실시간 대응을 요구하는 전략은 내지 않는다.**
모든 지시는 **아침에 예약주문으로 걸 수 있는 형태**여야 한다.

- ✗ "장 초반 흐름을 보고 판단"
- ✓ "459,000원 지정가 매도 322주를 걸어두세요"

시장가 주문은 소형주에서 위험하다. **지정가로 낸다.**

## 입력 — 받는 것

`차트` 탭이 켜진 시세 화면 캡처. 여기서 읽는 것:

| 읽는 값 | 쓰는 곳 |
|---|---|
| 현재가(종가)·전일비·등락률 | 손익·비중 계산 |
| 시가·고가·저가 | 그날 캔들 모양 (장대양봉, 위꼬리, 도지) |
| 거래량·거래대금 | 움직임에 수급이 실렸는지 |
| **5·20·60 이동평균** | 추세와 지지·저항 — **이게 차트를 대신한다** |
| 시가총액 | 발행주식수 교차검증 (시총 ÷ 주가) |

받은 값은 `data/prices-YYYYMMDD.json`에 저장한다. 전일 파일과 비교하면 변동이 나온다:

```bash
python3 scripts/portfolio.py --prices data/prices-20260818.json \
                             --compare data/prices-20260817.json
```

**차트 이미지는 평소에 필요 없다.** 이평값이 매일 갱신되기 때문이다.
다만 **매물대(지지·저항)는 종가만으로 갱신되지 않는다.** 그래서:

- 한 달에 한 번 정도 차트를 다시 받는다
- 그 사이라도 **신고가·신저가가 나오거나 하루 ±10% 이상 움직이면** 그 종목만 한 장 요청한다

## 밤사이 확인 — 🖤 블랙

미국 정규장은 **서머타임(3~11월) 기간에 한국시간 22:30~05:00**에 열린다.
즉 여름에는 **05:30이 마감 30분 뒤**라 확정 종가를 쓸 수 있다.

겨울(11~3월)에는 서머타임이 풀려 미국장이 **23:30~06:00**에 열린다.
**05:30은 마감 30분 전**이므로 그때 수치는 확정이 아니다.
**"장중, 마감 30분 전 기준"이라고 명시**하고 확정 수치로 쓰지 않는다.
결론이 갈릴 정도로 미국장이 출렁이는 날이면 06:00 이후 값으로 다시 확인한다.

매일 보는 것:

- WTI 유가
- 지정학 — 전쟁·분쟁 확대, 관세 발표, 수출규제

## 출력 — HTML 아티팩트

**`assets/brief-template.html`을 복사해서 그날 값으로 채운다.** 매일 새로 디자인하지 않는다.
같은 화면이 매일 같은 자리에 있어야 새벽에 5초 만에 읽힌다.

사용자는 05:30에 폰으로 이걸 읽고, 화요일이면 **06:10 필라테스**(월·금은 요가)를 간다.
읽고 주문을 걸 시간이 **10분 남짓**이다. 길게 쓰면 안 읽힌다.

템플릿의 구조와 각 칸에 넣을 것:

| 블록 | 내용 | 규칙 |
|---|---|---|
| **결론 배너** | "변경 없음" 또는 오늘의 액션 한 줄 | 액션이 있으면 `.verdict`에 `act` 클래스를 더해 좌측 띠가 경고색으로 바뀐다 |
| **밤사이** | 나스닥·S&P500·SOX·원달러·미10년물·WTI 칩 6개 | 확인 못 한 지표는 `.pending` 클래스로 "확인 예정" |
| **내 종목** | 종가·전일비·5/20/60 이평 대비 이격 | 이평 위는 `pos-over`, 아래는 `pos-under`, 데이터 없으면 `pos-mid` |
| **오늘 할 일** | 체크박스 목록 | 없으면 `.empty` 블록으로 "없습니다" — **빈 상태를 숨기지 않는다** |
| **걸어둔 트리거** | 현재가에서의 거리 막대 | 아래 계산법 참고 |
| **포트폴리오** | 총평가·손익·예수금·최대 비중 | |

### 등락 색은 뒤집지 않는다

`--up`은 빨강, `--down`은 파랑이다. 한국 증권앱과 같아야 한다.
미국식(상승 초록)으로 바꾸면 새벽에 반대로 읽는다. 구조색(`--accent`)을
적·청과 겹치지 않는 청록으로 뺀 이유가 이것이다.

### 트리거 거리 막대

가운데 세로선이 현재가다. 막대가 오른쪽(`i.d`)이면 가격이 더 **올라야** 닿고,
왼쪽(`i.u`)이면 더 **내려야** 닿는다.

```
거리(%) = (트리거가 − 현재가) / 현재가 × 100
막대 길이(%) = min(|거리| / 15, 1) × 50
```

15%를 넘으면 막대가 끝까지 찬다. 그보다 먼 트리거는 어차피 오늘 일이 아니다.
거리가 **2% 안쪽이면** 트리거 이름 옆에 `.near` 배지를 붙이고,
결론 배너에도 그 종목을 올린다.

### 휴장일

한국 증시가 쉬는 날(주말·공휴일)이면 **아티팩트를 만들지 않는다.**
2026년 8월 17일(월)처럼 대체공휴일에 걸리면 채팅에 한 줄로만 알린다.

### 같은 URL을 유지한다

브리핑은 매일 **같은 파일 경로에 덮어써서 재발행**한다. 그래야 URL이 안 바뀌고
사용자가 즐겨찾기 하나로 매일 아침 최신 브리핑을 연다. 날짜별로 새 파일을
만들면 아티팩트 목록이 매일 하나씩 늘어난다.

액션이 있는 날만 "오늘 할 일"이 채워진다. 없으면 **없다고 쓴다.**
채팅에는 아티팩트 링크와 **한 줄 요약**만 남긴다. 내용을 두 번 쓰지 않는다.

## 하지 말 것

- **매일 점수를 매기지 않는다.** 채점은 전체 협의체를 돌리는 주간 점검에서만
- **매일 신규 종목을 제안하지 않는다.** 신규는 재무·밸류에이션 확인이 필요하고
  그건 하루 아침에 할 수 있는 일이 아니다
- **하루 등락으로 결론을 뒤집지 않는다.** 재검토 조건은 이미 정해져 있다.
  그 조건이 발동했을 때만 바꾼다
- **밤사이 뉴스를 찾다가 못 찾았으면 "특이사항 없음"이라고 쓴다.**
  억지로 연결고리를 만들지 않는다

## 주간 정밀 점검은 따로

매일 브리핑은 **트리거 감시**이고, 전체 협의체 4라운드 토론은 **주 1회**면 충분하다.
아래 중 하나가 생기면 주중이라도 전체 토론을 돌린다:

- 보유 종목의 **분기 실적 발표**
- 한 종목이 하루 **±10% 이상** 움직임
- 매도·매수를 **실제로 체결**했을 때 (포트 구조가 바뀌므로)
- 사용자가 신규 종목을 검토하자고 할 때

## 뉴스를 판단에 넣는 법 — 이상수익률로 거른다

"오늘 이런 뉴스가 있었습니다"는 브리핑이 아니다. 뉴스는 매일 수백 개 나오고,
그중 주가를 움직인 것은 소수다. 사후에 아무 뉴스나 갖다 붙이면 그건 서사지 분석이 아니다.

순서를 뒤집는다. **뉴스를 읽고 주가를 설명하지 말고, 설명 안 되는 주가를 먼저 찾고
그 날짜로 뉴스를 검색한다.**

```bash
python3 scripts/factor_model.py --name 현대차 --top 6
```

거시 팩터(VIX·원달러·WTI)로 설명되는 부분을 걷어내면 **잔차 = 이상수익률**이 남는다.
그게 그 기업에 실제로 일어난 일이다.

| 이상수익률 | 뜻 | 할 일 |
|---|---|---|
| **±3σ 이상** | 거시로 설명 불가능한 사건 | **반드시 뉴스를 찾는다.** 못 찾으면 "원인 미확인"으로 남긴다 |
| ±1.5~3σ | 기업 고유 요인이 있었다 | 실적·수주 발표일과 대조한다 |
| ±1σ 미만 | 시장 따라간 날 | **뉴스를 붙이지 않는다.** 붙이면 없는 인과를 만드는 것이다 |

검증된 사례 (2026-08-16 실행):
- 삼성전자 2026-07-31 이상수익률 **+18.96%(+3.4σ)** → 검색 결과 2분기 영업이익
  89.4조(전년비 19배), 필라델피아 반도체 지수 상승, 외국인 매수
- 현대차 2026-06-23 이상수익률 **−11.72%(−3.0σ)** → 2분기 영업이익 2.9조로
  컨센서스 3.2조 하회, 미국의 한국산 12.5% 관세 발표

**날짜를 먼저 찾았고 뉴스가 뒤에 맞아떨어졌다.** 이 순서라야 인과를 지어내지 않는다.

## 거시 팩터 조달

`data/factors.json`. 시세 사이트는 프록시에 막혀 있고, GitHub 공개 데이터셋은 열려 있다.

```bash
curl -sS "https://raw.githubusercontent.com/datasets/finance-vix/main/data/vix-daily.csv"
curl -sS "https://raw.githubusercontent.com/datasets/oil-prices/main/data/wti-daily.csv"
curl -sS "https://raw.githubusercontent.com/datasets/exchange-rates/main/data/daily.csv"
```

| 팩터 | 상태 | 지연 |
|---|---|---|
| VIX | 자동 수집 | 당일 |
| WTI | 자동 수집 | 2~3일 |
| 원/달러 | 자동 수집 | 5~7일 |
| **SOX(필라델피아 반도체)** | **없음 — 캡처 필요** | |
| **나스닥·KOSPI 야간선물** | **없음 — 캡처 필요** | |

**시차를 반드시 맞춘다.** 미국 정규장은 한국시간 05:00에 끝나므로 미국 t일 종가는
한국 t+1일 개장 전에 확정된다. 미국계 팩터는 **1거래일 시차**로 붙이고,
원/달러는 국내 동시 거래이므로 동일자로 붙인다. 이걸 틀리면
"한국 주가가 오늘 밤 미국 지수를 예측했다"는 회귀가 나온다.
