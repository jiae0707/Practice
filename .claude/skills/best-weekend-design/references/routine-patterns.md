# 실제 루틴 패턴 (사용자의 기록에서 추출)

사용자가 실제로 써온 주말·평일 체크리스트 수십 일치를 분석한 결과다.
**이 파일은 "이 사람이 실제로 어떻게 사는가"의 근거**이고, 추측으로 일정을 채우는 것과
여기 있는 패턴을 조합하는 것은 결과물의 질이 완전히 다르다. 초안을 짜기 전에 읽는다.

---

## 가장 중요한 발견 — 활동을 잘게 쪼개서 관리한다

실제 기록은 **하루 15~30개 항목**이다. "세수", "선크림", "양치", "환기" 같은 5분짜리도
전부 적혀 있다. 체크박스를 지우는 데서 만족을 얻는 스타일이다.

그렇다고 시간표를 30줄로 만들면 못 쓴다. **두 층으로 낸다**:

- **시간표 블록** — 시간대를 차지하는 덩어리 (수영강습, 엄마집 점심, 사우나)
- **블록 안 체크리스트** — 그 시간에 함께 처리하는 잔업들 (설거지, 쓰레기, 환기, 세수)

하루 5개 이상이라는 제약은 **블록 기준**이고, 체크리스트 항목은 개수 제한과 무관하다.
잔업을 시간표 행으로 올리지 말고, 가까운 블록에 딸려 보내라.

---

## 항상 붙어 다니는 묶음

이 사람의 머릿속에서 하나로 묶여 있는 것들이다. 하나만 넣고 짝을 빠뜨리면 어색해진다.

| 앞 | 뒤 |
|---|---|
| 식사 | **설거지** (거의 즉시. 별도 블록 아님) |
| 사우나 | **사우나 정리** (+ 속옷 빨래가 자주 따라옴) |
| 수영 | **수영용품 정리** |
| 화분 물주기 | **꽃병 물갈기** (거의 항상 세트. 큰화분은 따로 취급) |
| 입을 옷 정하기 | **스타일러** |
| 엄마집 | **챙겨갈 물건** (아래 참고) |
| 빨래 | **널기 → 걷기 → 정리** (하루 안에 흩어져 배치) |
| 택배 | **정리 → 리뷰 작성 → (반품이면) 반품 신청·포장** |
| 청소기 | 화장실 청소 (주말 마무리 시간대에 함께) |

## 엄마집에 갈 때는 뭘 들고 간다

기록에 `엄마집(서류/레몬즙 전달)`, `엄마집(빈통/레몬즙2)`, `엄마집(커피포트/토스터기)`,
`엄마집 짐싸기(건전지, 필터, 비타민)`처럼 **거의 항상 괄호가 붙는다.**

일정에 엄마집을 넣을 때는 **"챙길 것" 칸을 비워두고 물어본다.** 전달할 게 없으면 없는 대로
좋지만, 있는데 빠뜨리면 다시 가야 한다. 짐이 여러 개면 출발 전 "엄마집 짐싸기"를
5분짜리 체크 항목으로 앞에 붙인다.

## 일요일 저녁 = 다음 주 준비 세트

거의 매주 반복되는 조합이다. 일요일(또는 연휴 마지막 날) 늦은 오후~저녁에 배치한다.

- 입을 옷 정하기 + 스타일러
- **회사 짐 싸기** — 양말, 속옷, 이어폰, 비타민, 화장솜
- 비타민 챙기기
- 커피 타오기
- 빨래 정리 / 건조대 정리
- 화장실 청소 · 샤워 · 팩

## 자주 가는 곳

| 장소 | 무엇 |
|---|---|
| **엄마집** | 점심, 물건 전달. 주말마다, 토·일 이틀 다 가는 주도 많음 |
| **커뮤니티 사우나** | 주말 상시. 저녁이 많고 오전도 있음 |
| **도서관** | 책 반납 / 책 빌리기 — 반납일이 있으니 주말에 묶임 |
| **알파마트 / 이마트 / 가락시장 / 다이소** | 장보기, 와인, 생필품 |
| **한의원 / 필라테스 / 도수치료 / 치유외과** | 예약제. 시간이 고정이라 앵커가 된다 |
| **미용실 / 꽃집** | 가끔, 예약 필요 |
| **잠실(롯데백화점·롯데월드몰)** | 쇼핑·문화 |

## 운동 레퍼토리

아침 러닝 · 스트레칭(수시, 짧게 여러 번) · 필라테스(주로 평일) · 골프(주말, 예약·연습·짐싸기가 세트) ·
마라톤(대회 신청) · 자전거 · 산책. **수영강습이 최근 추가됨(매주 토 10시).**

스트레칭은 하루에 두세 번 흩어져 나온다 — 블록이 아니라 체크 항목으로 다루는 게 맞다.

## 식사 레퍼토리

거의 조리 없이 **조합해서 먹는다.** 자주 등장하는 것들:

- **단백질**: 계란(1~3개, 삶기·수란·오믈렛), 닭가슴살, 두부, 훈제오리
- **유제품**: 그릭요거트(직접 만들기도 함), 두유
- **견과·과일**: 호두, 아몬드, 사과+땅콩버터(고정 조합), 딸기, 블루베리, 무화과, 감말랭이, 토마토
- **탄수화물**: 누룽지, 라면·누들면, 고구마, 빵류(휘낭시에·까눌레·에그타르트)
- **곁들임**: 김치(거의 매끼)

**커피는 하루 2~4회.** 콜드브루 직접 만들기, 원두 갈기, 에스프레소 추출, "커피 타오기"가
따로 기록될 만큼 비중이 크다. 커피는 활동이 아니라 배경이다 — 블록으로 만들지 말고
아침·오후 체크 항목으로 둔다.

**와인**은 기록상 상당히 자주 등장한다(막걸리도). 다만 본인이 줄이고 싶다고 말했으므로
**내가 먼저 넣지 않는다.** 저녁 마무리 시간대를 비워두면 본인이 알아서 채운다.
말씀하시면 그대로 넣고, 그때 건강 이야기를 덧붙이지 않는다.

## 집안일 레퍼토리

빨래(겉옷·속옷·수건·이불·발매트를 **종류별로 따로** 돌림) · 설거지 · 청소기(로봇청소기 포함) ·
화장실 청소 · 현관 바닥 닦기 · 창틀 닦기 · 환기 · 쓰레기/재활용 버리기 · 주방 정리 ·
싱크대 정리 · 냉장고·김치 정리 · 서랍 정리 · 화분 관리(잎 닦기, 정리, 마사토, 큰화분) ·
베란다 청소 · 세탁기 먼지망 청소

계절성 대형 과업: 옷방 정비, 겨울옷 정리, 에어컨·실외기 청소, 온수매트 세팅/정리,
베란다 곰팡이 제거, 크리스마스 장식

## 그 밖에 눈에 띄는 것

- **온라인 쇼핑 비중이 크다.** 구매 → 택배 정리 → 리뷰 작성 → 반품/환불이 하나의 흐름
- **행정·금융 잡무**가 꾸준하다: 보험료, 관리비, 카드 재발급, 서류, 세무 상담, 예약 전화
- **TV·유튜브**: 나 혼자 산다(토요일), 놀라운 토요일, 코난, 넷플릭스
- **게임**이 짧게 자주 등장한다 — 휴식 후보로 넣어도 좋다
- 기상 시각이 5시가 아닌 날도 있다(7시, 8시). 연휴나 컨디션에 따라 유연하다
