# 사용자 프로필 → 저장소 공용 파일로 이동했다

이 스킬만이 아니라 **모든 작업에 적용되어야 할 정보**이므로
`.claude/context/about-me.md`로 옮겼다. 여기에 사본을 두면 두 파일이 갈라지고,
어느 쪽이 최신인지 알 수 없게 된다.

**주말 일정을 짜기 전에 `.claude/context/about-me.md`를 읽는다.**
거기에 있는 것: 기상·취침, 퇴근 후 시간, 건강과 운동, 술, 집과 취향(미니멀·우드톤),
미술·자연 취향, 사는 곳과 이동수단, 2식 생활과 요리 한계, 씻기 규칙,
일하는 방식(체크리스트·후보 제시·수정 요청 처리), 자유시간 후보 풀.

## 주말 설계에서 특히 자주 걸리는 것

- **활동 가능 시간대 05:00~21:00.** 검증할 때 `--window 05:00-21:00`으로 확인한다
- **오전 5~9시가 황금 시간대.** 집안일·집중 작업·대형 과업을 여기 배치한다
- **저녁 식사 행을 만들지 않는다.** 17시 이후가 비므로 느린 활동으로 채운다
- **엄마집 점심**은 다른 일정이 없는 날마다, 12~13시, 최소 1시간
- **씻기는 배치로 푼다** — 수영·사우나를 이틀 간격에 맞추면 샤워 블록이 필요 없다
- **술은 먼저 넣지 않는다.** 본인이 원하면 그대로 넣고 건강 이야기를 붙이지 않는다
