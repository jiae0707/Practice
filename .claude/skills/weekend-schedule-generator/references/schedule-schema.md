# 일정 JSON 형식

`scripts/validate_schedule.py`가 읽는 형식. 최종안이 확정되면 이 형식으로 저장하고
검증을 돌린 뒤, 통과한 내용을 사람이 읽을 표로 옮긴다.
(작업 파일이므로 사용자 저장소를 어지럽히지 않도록 임시 디렉터리에 쓴다.)

```json
{
  "theme": "소셜",
  "region": "서울 성수·연남",
  "days": [
    {
      "label": "토요일",
      "date": "2026-08-15",
      "activities": [
        {
          "start": "09:00",
          "end": "09:40",
          "title": "아침 식사 + 커피",
          "category": "식사",
          "zone": "집",
          "travel_min_from_prev": 0,
          "cost": 0,
          "notes": "간단히"
        },
        {
          "start": "11:00",
          "end": "12:30",
          "title": "사진전 관람",
          "category": "문화",
          "zone": "성수",
          "travel_min_from_prev": 35,
          "cost": 15000,
          "notes": "11시 오픈 직후가 한산. 도슨트 11:30"
        }
      ]
    }
  ],
  "scores": {
    "블랙": { "테마 적합성": 9.8, "동선 효율": 9.6, "다양성": 9.6, "실행 가능성": 9.7, "완성도": 9.8 },
    "레드": { "테마 적합성": 9.5, "동선 효율": 9.6, "다양성": 9.4, "실행 가능성": 9.5, "완성도": 9.4 },
    "블루": { "...": 0 },
    "실버": { "...": 0 },
    "골드": { "...": 0 }
  }
}
```

## 필드

| 필드 | 필수 | 설명 |
|---|---|---|
| `theme` | ✅ | 사용자가 고른 테마 |
| `region` | | 주 활동 지역. 집 위주면 `"집"` |
| `days[].label` | ✅ | `"토요일"` 등 |
| `days[].date` | | `YYYY-MM-DD` |
| `activities[].start` / `end` | ✅ | `HH:MM` 24시간제. `end`가 `start`보다 이르면 자정을 넘긴 것으로 본다 |
| `activities[].title` | ✅ | 활동 이름. 중복 검사의 기준 |
| `activities[].category` | ✅ | 아래 목록 참고 |
| `activities[].zone` | ✅ | 지역 단위. 집은 `"집"`으로 통일 (동선 검사에서 출발·복귀로 취급) |
| `activities[].travel_min_from_prev` | | 직전 활동 장소에서 오는 데 걸리는 분. 기본 0 |
| `activities[].cost` | | 원 단위 정수 |
| `activities[].notes` | | 시간대 근거, 예약 여부, 대안 등 |
| `scores` | ✅ | 5인 × 5항목. 사람별 5항목 평균이 그 사람 점수 |

## 카테고리

`식사` `카페` `문화` `쇼핑` `운동` `산책·자연` `집안일` `집개선` `여가` `학습·작업`
`휴식` `이동` `사교`

- **활동 수 계산에서 제외**: `식사`, `이동`
- **하루 2회 초과 허용**: `식사`, `휴식` (나머지 카테고리는 하루 2회까지)

## 검증 결과 읽는 법

- `ERROR` — 스킬의 하드 제약 위반. 고치기 전엔 사용자에게 내놓지 않는다
- `WARN` — 대개 문제지만 이유가 있으면 통과 가능. 통과시킬 땐 왜 괜찮은지 메모에 남긴다
  (예: "일요일 이동 2회 초과는 픽업 때문이며 사용자가 요청함")

종료 코드는 `ERROR`가 하나라도 있으면 1, 아니면 0이다.
