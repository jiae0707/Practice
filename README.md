# Practice

## 최고의 주말 설계 (best-weekend-design)

`.claude/skills/best-weekend-design/` — 테마를 고르면 성격이 다른 5명이 최소 4라운드
토론해서, **내 생활 리듬에 맞는** 주말 시간표를 만드는 Claude Code 스킬.

### 쓰는 법

이 저장소에서 Claude Code를 열고 그냥 말하면 된다.

```
이번 주말 계획 좀 짜줘
토요일에 성수에서 친구 만나는데 하루 코스 짜줘
집에서 보내는 주말인데 청소랑 쉬는 거 반반으로
아까 그 일정에서 오후에 갑자기 서점 가고 싶어졌어
```

마지막처럼 **중간에 바꿔 달라고 하면 그 이후 일정을 다시 계산**한다.
항목 하나만 갈아 끼우지 않는다 — 시간이 밀리면 뒤가 밀리고 장소가 바뀌면 동선이 바뀐다.

### 어떻게 동작하나

| 역할 | 하는 일 |
|---|---|
| 🖤 블랙 | 일정을 짜고 지적을 받아 고친다 |
| ❤️ 레드 | 효율·테마 적합성을 냉정하게 평가한다. 이 일정의 유일한 적대자 |
| 💙 블루 | 업그레이드 아이디어와 우천·혼잡 대안을 붙인다 |
| 🩶 실버 | 20년 경력 살림 전문가. 집안일 순서와 현실적 소요 시간을 잡는다 |
| 💛 골드 | 안목 있는 인플루언서. 장소·시간대·아이템을 챙긴다 |

최소 4라운드(하한이지 목표가 아니다) 토론 후 5명이 5개 항목(테마 적합성 / 동선 효율 /
다양성 / 실행 가능성 / 완성도)을 채점한다. 평균 9.5점 미만이면 **최저점을 준 사람이
개선안을 직접 제시**하고 블랙이 그 항목만 고쳐 재채점한다.

점수는 **일정의 실제 품질에만** 근거한다. 라운드를 많이 돌았다는 이유로 점수를
올리지 않으며, 최선을 다해도 9.2라면 9.2로 보고하고 무엇이 충돌하는지 설명한다.

### 설계 원칙

**밀도** — 하루 최소 5개의 *의미 있는* 활동 / 이동·식사·대기시간을 개수에 넣지 않음 /
같거나 유사한 활동 반복 금지 / 빡빡하지 않게, 자유시간·완충시간 필수

**동선** — 지역을 묶어서 설계 / 이동수단과 실제 이동시간 반영 / 이미 잡힌 약속이 앵커

**내용** — 친구 약속이면 주변 전시·공연·카페·식당까지 / 집이면 집안일·집 개선·요리·
운동·취미·휴식을 균형 있게 / 생산성 테마에도 휴식을 / 휴식 테마도 무의미하게 흘려보내지 않기

**정확성** — 장소는 웹 검색으로 영업 여부와 **그 날짜** 운영 여부까지 확인

### 내 정보 — 두 파일이 기억을 담당한다

대화는 세션이 끝나면 사라지지만 파일은 남는다. 그래서 개인 정보는 파일에 저장한다.

**`references/user-profile.md`** — 생활 리듬(기상 05:00 / 취침 21:00), 고정 습관,
선호와 기피, 수정 요청 처리 방식. 매번 가장 먼저 읽는다.
05:00~21:00 밖의 일정은 검증에서 막힌다.

**`references/recurring-rules.md`** — 주기 반복 활동.

| 활동 | 주기 | 마지막 실행 | 배치 힌트 |
|---|---|---|---|
| 화분 물주기 | 2주 | 2026-08-08 | 화분 4개. 아침, 10분 |
| 꽃병 물갈이 | 매주 | 2026-08-08 | 수경 꽃병 4개. 아침, 10분 |
| 다음 주 입을 옷 정하기 | 매주 | 2026-08-09 | 일요일 17~19시 |
| 엄마집 식사 | 조건부 | – | 친구 약속이 없는 주말. 도보 10분 |

`마지막 실행 + 주기 ≤ 주말 마지막 날`이면 도래로 보고, 일정에 없으면 ERROR로 잡힌다.
일정 확정 후 마지막 실행 날짜를 갱신한다. 새 규칙은 표에 줄을 추가하거나
"앞으로 주말마다 ~할래"라고 말하면 된다.

### 하드 제약

- 하루 5개 이상 의미 있는 활동 (식사·이동·5분 습관 제외)
- 같은 활동 반복 금지, 유사 카테고리 하루 2회까지
- 동선 핑퐁(A→B→A) 금지, 지역 이동 하루 2회 이하
- 활동 간 버퍼 15분, 지역 이동 시 이동시간 + 15분
- 기상~취침 시간대(05:00~21:00) 밖 활동 금지
- 주기가 돌아온 고정 규칙 이행
- 5인 평균 9.5점 이상, 개별 9.0점 미만 없음

눈으로 확인하지 않고 스크립트로 검증한다:

```bash
python3 .claude/skills/best-weekend-design/scripts/validate_schedule.py \
        .claude/skills/best-weekend-design/assets/example-schedule.json \
        --rules .claude/skills/best-weekend-design/references/recurring-rules.md \
        --window 05:00-21:00
```

`assets/example-schedule.json`은 모든 제약을 통과하는 예시다
(약속 없는 주말 = 엄마집 식사 포함, 꽃병 물갈이 도래, 화분은 8/22이 다음 차례).

### 구성

```
.claude/skills/best-weekend-design/
├── SKILL.md                        # 설계 원칙, 진행 순서, 상황별 무게중심
├── references/
│   ├── user-profile.md             # 내 생활 리듬과 선호 (여기를 편집)
│   ├── recurring-rules.md          # 내 고정 반복 활동 (여기를 편집)
│   ├── personas.md                 # 5인의 성격과 체크리스트
│   ├── debate-protocol.md          # 라운드 구조, 채점, 점수 인플레 방지
│   ├── themes.md                   # 생산성 / 휴식 / 소셜 / 집콕 정비
│   └── schedule-schema.md          # 검증용 JSON 형식
├── scripts/validate_schedule.py    # 하드 제약 자동 검증
└── assets/
    ├── output-template.md          # 최종 출력 템플릿
    └── example-schedule.json       # 통과 예시
```
